# FT3–TSH coupling does not establish incremental resting-pulse prediction across two NHANES cross-sections

## Abstract and scoped claim
An FT3-by-logTSH interaction, motivated by peripheral thyroid action in its pituitary-feedback context, did **not establish improved resting radial-pulse prediction** beyond flexible individual hormones, established thyroid-sensitivity indices and clinical covariates. In a frozen transfer from NHANES 2007–2008 (n=2,236) to the independently sampled 2011–2012 cross-section (n=769), weighted MSE fell from 130.687 to 130.179 (beats/minute)²: gain 0.509, 95% joint source-refit/target survey-PSU bootstrap interval −1.114 to 2.407. RMSE changed from 11.432 to 11.410 beats/minute, while MAE increased from 8.934 to 8.936. This is an inconclusive incremental-prediction result, not an equivalence test, causal finding, disease prediction, or demonstration of a useful new biomarker.

## Question and scientific motivation
The [Asklepios primary population study](https://pubmed.ncbi.nlm.nih.gov/23339744/) associated FT3 with heart rate; a [2025 primary study](https://pubmed.ncbi.nlm.nih.gov/39986552/) examined thyroid-sensitivity indices and heart rate. These motivate testing whether a peripheral hormone's pulse information depends on feedback context after accounting for those established summaries. Neither an FT3 association nor a simple thyroid ratio is claimed as new. The proposed extra information is one nonlinear cross-hormone interaction beyond an unusually strong additive baseline. Absence from current clinical analysis and absolute scientific novelty are not established by this experiment.

## Outcome, baseline and proposed pattern
Outcome BPXPLS is a30-second radial pulse count multiplied by2, not an ECG rhythm or24-hour heart rate. See [source](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2007/DataFiles/BPX_E.htm) and [target BPX protocols](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2011/DataFiles/BPX_G.htm). Pulse measurement error and the two-beat resolution can obscure small biological signals.

Baseline: ridge regression alpha1, intercept unpenalized. Source-trained additive cubic B-splines with3 uniformly spaced knots and linear extrapolation cover age, BMI, FT3, FT4, logTSH, FT3/FT4, TSHI, TT4RI, TFQI. TSHI=logTSH+0.1345×FT4(pmol/L); TT4RI=TSH×FT4(pmol/L); TFQI=F_source(FT4)+F_source(TSH)−1 using unweighted empirical CDFs with right ties. This implementation is a source-referenced index, not a population-standardized diagnostic TFQI. Sex, race/ethnicity, ever/current smoking categories and reported beta-blocker use are one-hot encoded. Beta blockers are identified using the explicit generic-name list in code. Baseline definitions reflect standard hormone/sensitivity measures; the ridge model itself is an analytic comparator, not an established clinical prediction tool.

The augmented model adds z_source(FT3)×z_source(logTSH), standardized again along with the baseline design. Source weighted means/scales, spline knots, CDFs and category encoding are frozen for target prediction. Each fold/bootstrap fit learns its transformations only from its own source rows. No target outcome, target centering or recalibration is used. Positive MSE gain means baseline MSE minus augmented MSE; prespecified success required a positive gain and95% interval excluding0. No hyperparameter was selected using target performance.

## Uncertainty and challenge results
Use seed181835. Each of300 bootstrap iterations samples m−1PSUs with replacement within each stratum having mPSUs, assigns multiplicity×m/(m−1), refits both source models, and independently reweights target PSUs. Interval is the percentile interval of paired MSE gains; it includes source estimation and target survey variation, but not model-choice uncertainty or correction for complete-case selection. Few strata and only769 target persons make tails uncertain.

Source fivefold grouped-by-PSU CV gains were −0.535,+0.344,+0.224,+0.304,−0.796: no consistent improvement. Target sensitivity MSE gains: ridge0.1,+0.429; ridge10,+0.422;5knots,+0.159; unweighted,−0.101; no beta-blocker users,+0.445; all3 pairwise hormone products,+0.523. Frozen sex-stratum gains were+0.725 (425 men) and+0.254 (344 women). These descriptive secondary checks are not separate discoveries and have no multiple-testing-adjusted significance claim. Adding all products tests a broader nonlinear representation, not confirmation of this particular product. A post-primary regular-pulse-only refit is also retained in results.json.

In100 source feature-permutation challenges, gain quantiles(min,2.5%,median,97.5%,max) were −1.573,−1.072,−0.006,+0.519,+0.780. The observed+0.509 is within this empirical range. Unconditional shuffling breaks predictor dependence and is a sanity challenge, not a valid conditional-independence p-value. These diagnostics and the slight MAE deterioration reinforce the narrow inconclusive claim; they do not prove an absent physiological interaction. The positive primary point estimate explains only0.389% of baseline MSE.

## Limitations and future test
Cross-sectional co-measurement does not predict future illness or identify causal feedback physiology. A single radial count is influenced by fitness, autonomic tone, recent stimulants, other medication, temperature, time of day and comorbidity. BMI/smoking/beta adjustment does not eliminate these. Assay laboratory changes between cycles and known thyroid measurement issues can cause domain shift; no total-T4 variable is used, so total-T4 correction equations are not applied. Complete-case/hormone restrictions and small target sampling reduce power. Baseline index collinearity is stabilized by ridge but coefficients, including the interaction coefficient, lack a standalone mechanistic interpretation. Numerous possible interactions were not tested; failure of this prespecified one does not rule out richer physiology. A future independently recruited clinical observational study could preregister this interaction, harmonize assays, measure repeat ECG/resting pulse with time-of-day and medication control, and test calibrated prediction against the same rich baseline. None of that study has been performed here.
